一、适合用筛法的场景
1.需要一次性求出 2～n 全部素数
不是只判断一个数，是要批量找出一整片所有质数。
2.n 比较大（几百、几千、上万、上百万）
普通逐个判断太慢，筛法速度快很多。
3.需要多次查询素数
先一次性用筛法预处理好所有素数，后面每次查表直接用，不用重复计算。

题目要求：统计素数个数、输出区间所有素数、素数打表，标准模板就是筛法。
二、不适合用筛法的场景
1.只单独判断某一个数是不是素数
比如只判断 997 是不是质数，没必要开数组搞筛法，直接单独判断更简单。
2.n 特别小（比如 n＜10）
暴力写几句就能搞定，用筛法反而多写代码、多余。
3.内存极其受限
筛法要开一个布尔数组占内存，如果环境不能开数组，就不能用。
代码：
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

/**
 * 埃拉托斯特尼筛法求素数（带执行时间统计）
 */
public class PrimeSieve {

    /**
     * 筛选所有 ≤ n 的素数
     * @param n 上限
     * @return 素数列表
     */
    public static List<Integer> sieve(int n) {
        if (n < 2) {
            throw new IllegalArgumentException("n 必须大于等于 2");
        }

        // 1. 初始化：默认所有数都是素数
        boolean[] isPrime = new boolean[n + 1];
        Arrays.fill(isPrime, true);
        isPrime[0] = false;
        isPrime[1] = false;

        // 2. 标记非素数：只需循环到 sqrt(n)
        for (int i = 2; i * i <= n; i++) {
            if (isPrime[i]) {
                // 从 i*i 开始标记（前面的倍数已被更小的数标记过）
                for (int j = i * i; j <= n; j += i) {
                    isPrime[j] = false;
                }
            }
        }

        // 3. 收集结果
        List<Integer> primes = new ArrayList<>();
        for (int i = 2; i <= n; i++) {
            if (isPrime[i]) {
                primes.add(i);
            }
        }
        return primes;
    }

    public static void main(String[] args) {
        // 你想测试多大范围，改这里就行
        int max = 100000000; // 试100万、1000万都可以

        // ===== 计时开始 =====
        long start = System.currentTimeMillis();

        // 执行筛法
        List<Integer> primes = sieve(max);

        // ===== 计时结束 =====
        long end = System.currentTimeMillis();

        System.out.println("≤ " + max + " 的素数总数：" + primes.size() + " 个");
        System.out.println("代码执行耗时：" + (end - start) + " 毫秒");

        // 数字小的时候才打印列表，大了就别打印，不然打印很慢影响时间
        if (max <= 100000) {
            System.out.println("素数列表：");
            System.out.println(primes);
        }
    }
}
