###  一、用处
1. 专门用来固定有限、不会变的状态：订单状态、审批状态、性别、业务类型、支付类型等。
2. 替代代码里裸写的 0/1/2/3 魔法数字。
3. 可以存 编码 + 文字描述，后端开发经常用来和数据库状态码对应。
### 二、优势
1. 可读性强：看到 WAIT_PAY 就懂，不用猜数字 1 代表什么。
2. 类型安全：只能传规定好的枚举值，不能随便乱传数字，减少 bug。
3. 统一管理：所有状态全写在一个枚举里，改一处全局生效。
4. 自带扩展：可以加属性、加方法，实现根据编码反向查找状态。

```

public class OrderStatusDemo {

    // 订单状态枚举
    public enum OrderStatus {
        // 枚举常量：编码 + 描述
        WAIT_PAY(1, "待支付"),
        PAID(2, "已支付"),
        DELIVERED(3, "已发货"),
        FINISHED(4, "已完成"),
        CANCEL(5, "已取消");

        private final int code;
        private final String desc;

        // 枚举私有构造方法
        OrderStatus(int code, String desc) {
            this.code = code;
            this.desc = desc;
        }

        // getter 方法
        public int getCode() {
            return code;
        }
        public String getDesc() {
            return desc;
        }

        // 根据编码反向匹配枚举
        public static OrderStatus getByCode(int code) {
            for (OrderStatus status : OrderStatus.values()) {
                if (status.getCode() == code) {
                    return status;
                }
            }
            return null;
        }
    }

```
```
    // 测试主方法
    public static void main(String[] args) {
        // 1. 直接使用枚举，不用魔法数字 1、2、3
        OrderStatus status1 = OrderStatus.PAID;
        System.out.println("当前状态：" + status1.getCode() + " -> " + status1.getDesc());

        // 2. 根据数字编码反向查询状态
        OrderStatus status2 = OrderStatus.getByCode(3);
        System.out.println("编码3对应状态：" + status2.getDesc());

        // 3. 遍历所有订单状态
        System.out.println("\n所有订单状态列表：");
        for (OrderStatus s : OrderStatus.values()) {
            System.out.println(s.getCode() + " : " + s.getDesc());
        }
    }
}
```
