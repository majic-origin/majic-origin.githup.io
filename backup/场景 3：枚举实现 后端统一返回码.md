### 一.用处

1. 后端项目统一管理接口状态码和提示文案；
2. 替代代码里裸写 200、400、500 等魔法数字；
3. 前后端约定好固定返回码，全局统一标准；
4. 异常、参数错误、权限不足、成功响应，全部集中在一个枚举维护。

### 二、优势

1. 消灭魔法数字：不再裸写 200/400/500，可读性拉满；
2. 全局统一规范：所有接口返回码统一维护，不用各处零散定义；
3. 易维护：要改提示语，只改枚举一处，全局生效；
4. 类型安全：只能用定义好的返回码，不会随便乱写数字出错；
5. 结构规整：状态码 + 提示语绑定在一起，业务语义清晰。


```

public class ResultCodeDemo {

    /**
     * 场景3：后端全局统一返回码枚举
     * 用途：接口固定状态码、提示信息统一规范
     */
    public enum ResultCode {
        // 1. 枚举常量：状态码 + 提示信息
        SUCCESS(200, "请求成功"),
        PARAM_ERROR(400, "参数非法"),
        UNAUTHORIZED(401, "未登录或权限不足"),
        NOT_FOUND(404, "资源不存在"),
        SERVER_ERROR(500, "服务器内部异常");

        // 2. 成员变量：状态码、提示文案
        private final int code;
        private final String msg;

        // 3. 枚举私有构造方法：给常量赋值
        ResultCode(int code, String msg) {
            this.code = code;
            this.msg = msg;
        }

        // 4. getter 方法：外部获取属性
        public int getCode() {
            return code;
        }
        public String getMsg() {
            return msg;
        }
    }

```

   ```
 // 测试 main 方法
    public static void main(String[] args) {
        // 使用1：直接拿成功码
        System.out.println("状态码：" + ResultCode.SUCCESS.getCode());
        System.out.println("提示信息：" + ResultCode.SUCCESS.getMsg());

        // 使用2：拿错误码
        System.out.println("\n状态码：" + ResultCode.PARAM_ERROR.getCode());
        System.out.println("提示信息：" + ResultCode.PARAM_ERROR.getMsg());

        // 遍历所有返回码
        System.out.println("\n全局所有返回码列表：");
        for (ResultCode code : ResultCode.values()) {
            System.out.println(code.getCode() + " -> " + code.getMsg());
        }
    }
}`
```
